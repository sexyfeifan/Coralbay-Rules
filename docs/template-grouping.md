# 共用模板分组方案

4.16.0 在妙妙屋X、PPanel 和 MihomoPro 覆写页面提供共用的分组设置。每个入口可以使用共用方案，或保存自己的独立方案。保存设置与生成文件是两个动作；修改设置不会覆盖已经交付的固定版本文件。

## 使用流程

1. 打开目标模板页面，选择支持的客户端与分流规则来源。
2. 在“分组设置”中选择使用共用方案或当前入口的独立方案。
3. 设置业务分类、默认出口、地区、测速与均衡、图标和高级选项。分类列表可以排序。
4. 可粘贴节点名称检查地区归属。名称预览不需要节点密码或订阅令牌，也不测试节点连接。
5. 保存方案，生成配置，核对生成结果里的客户端、来源、规则版本和方案标识。
6. 从新方案的产物区打开、下载或复制配置。基础模板的旧下载入口仍代表原来的固定模板。

妙妙屋X 的 YAML 先导入“模板管理”，再绑定节点订阅。PPanel 的 YAML 下载文件含 Go 模板表达式，应粘贴至客户端订阅模板设置，由 PPanel 渲染。MihomoPro 必须使用同一次生成的覆写与完整配置，导入覆写后填写节点订阅。

## 分组含义

- **全球自动**：在全部订阅节点中按检测结果自动选择。
- **全球手动**：直接选择订阅中的单节点。
- **默认出口**：由多个业务分类共享的选择，初始值可在方案中设置。客户端保存过的选择可能优先于新配置的初始顺序。
- **故障转移**：按候选顺序选择可用节点。
- **地区自动、地区均衡、地区手动**：三种模式使用同一地区节点。手动组直接列出节点，不依赖一个可能在模板渲染时变空的中间策略组。

业务分类可显示全部单节点，也可引用上述全局及地区组。广告、苹果和国内分类拥有独立的初始选择；关闭分类时仍须保留其流量的有效去向，不能留下无效规则引用。

妙妙屋与 PPanel 的业务组选项按全局选择、单节点、地区自动／均衡／手动排列。原生 Mihomo 覆写中的订阅提供者节点由内核运行时加入，可能显示在固定地区选项之后；节点仍可直接选择。

## 地区覆盖

独立地区先分配，剩余节点进入亚洲、欧洲、北美洲、南美洲、大洋洲、非洲等大区，最后以“其他／未识别”收集无法识别的节点。大区排除已经归属的独立地区。一个节点的地理归属只有一个，在自动、均衡、手动三种模式中同时出现是正常行为。

名称可包含中文、英文、代码、城市或旗帜。中转名称、别名可能产生多个候选地区；预览会显示歧义，并可添加覆盖规则。名称识别不是出口 IP 定位，不能据此保证服务器的真实国家。

人工匹配会提升整个目标地区的匹配优先级，重复目标合并；请结合歧义预览核对中转名称。裸两字母 ISO 代码要求大写，或使用带编号的小写代码（如 `hk01`），避免普通英文 `in`、`no`、`it` 被识别成国家。

节点名称预览只证明这些名称的分配结果；模板生成时没有用户的真实节点，不能预先承诺某个地区一定非空。妙妙屋生成订阅时移除空地区组；原生 Mihomo 无匹配节点的地区组会拒绝连接，不会静默直连。请勿选择没有节点的地区作为默认出口，或改选“全球自动”。

## 规则、媒体和更新

业务规则沿用已验证的 666OS / YYDS Pro_cn。可单独开启 YouTube、Netflix、Disney、Spotify 分类；生成器将相关规则放在覆盖它们的宽泛媒体／平台规则之前。不开启时继续使用基础分流。媒体分类不会修改节点连接字段。

本机／上游选择指向同一已验证规则版本。规则同步继续运行，镜像或上游暂时失败时已有固定产物仍可使用；采用新的规则版本需要刷新来源并重新生成、导入模板。规则、模板输入、分组方案和生成器版本共同参与产物身份，同一旧链接不会被悄悄替换成另一份配置。

均衡算法可选择一致性哈希、轮询或粘性会话。均衡按请求或连接分配节点，不会叠加单条连接的带宽。DNS、IPv6、嗅探设置只在支持的输出中生效，默认保留基础配置。

## 支持范围

| 入口 | 共用分组方案输出 |
| --- | --- |
| 妙妙屋X | Clash V3 / Mihomo YAML |
| PPanel | Mihomo、OpenClash，以及使用 Mihomo 内核的 Clash 模板 |
| MihomoPro | 配对的完整 YAML 与 OpenClash 覆写 |
| 妙妙屋 Surge / Loon、PPanel 其他客户端 | 继续提供原有模板；尚未开放这套地区均衡方案 |

不同目标各自生成模板语法，不把妙妙屋占位符交给 PPanel 或原生内核。不支持的客户端组合会明确拒绝生成，不静默返回另一客户端的格式。

升级前备份整个 `data/`、`.env` 和 `compose.yaml`。共用设置保存在 `data/settings/`，方案产物按固定标识保留；不要只备份程序镜像。
